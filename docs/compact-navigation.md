# 紧凑顶部导航

统一网页不再保留常驻左侧栏。顶部显示当前工作空间，点击即可展开完整模式菜单；
概览入口仍在 OpenArm 标识和菜单中。连接设置、新窗口打开、明确确认的重新加载
放到顶部更多菜单。桌面顶部高 50px，窄屏高 48px；内容区使用剩余宽度和高度。
概览卡片、工具栏、模型页表单和留白同步收紧，窄屏菜单不变成横向滚动的七个标签。

打开、关闭模式菜单只是展示操作，不启动/停止服务，不删除或重建 iframe。真正
切换模式仍使用原有交接：确认停止互斥控制，正常退出后才移除旧控制页面。取消、
失败或切到感知页面不丢弃原控制 iframe；URL hash 和深链接继续可用。重新加载仍
要求确认，不能为了刷新外观而悄悄断开控制浏览器。

连接状态和红色 **停止运动** 入口始终保留在外层顶部，不藏进菜单，也不随着操作
区滚动消失。停止入口在模式切换、加载或状态读取失败期间仍可用，确认对话框中
也提供停止入口。它请求本平台模型会话和平台拥有的运动服务正常停止，不停相机、
触觉等独立采集；不强杀、不自动重新启动、不触发自动归位，也不提前释放尚未确认
失能的模型租约。外部启动的控制器不能由本平台接管或强停，会明确提示原入口处理。
这是软件停止请求，**不是硬件急停**，不能替代现场安全措施。attach-only 模式禁用。

显式仿真保留“仿真 · 实物禁用”标识。CAN 状态只表示当前已配置只读观察的状态，
不是任务成功或整机安全证明；没有观察配置时显示“CAN 未检查”。

布局验证使用隔离的本地网页夹具与模拟管理器，不连接 CAN、相机或模型，也不会
访问实物工作站。设备配置与已有控制/停止边界不由外观改动替代。
