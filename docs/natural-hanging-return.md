# 双臂下垂与已标定零位

网页的 **双臂下垂** 会让两条从臂的 J1–J7 同步回到已有的电机标定零位，
夹爪保持进入时的位置。它不是返回本轮开始前的任意姿态，也不是直接断电任其落下。
完成双臂反馈到位检查后正常失能。
失能包括夹爪电机；“夹爪保持”仅指运动中不重放开合命令，不保证失能后仍能夹住物体。

零偏由已经完成的硬件标定写入电机，不是从模型的 policy profile 读取。仓库保存
“回到已标定 0 位”的约定与通用控制逻辑；机器标定报告仍属于安装级外部证据。
不需要重填十四个目标角，也不会重新写零位、寻止挡或执行标定。

模型页提供：

- **双臂下垂**：无需选择或加载模型，不依赖模型的准备路径、几何标定或
  `return_home` 配置。自动复用已注册模型目录中唯一的 Classic 硬件 profile 与
  已配置的控制环境；该 profile 必须明确左右 CAN 映射。存在不同硬件 profile 时
  拒绝猜测。机器接线配置仍需存在，但不增加一份下垂角度配置。
- 两条总线都完成预检后才允许任一臂使能；一臂预检失败，两臂都不开始运动。
  使用既有 `HomeCoordinator`：平滑同步回零、网页按钮峰值 10°/s，双臂均需在既有 5°
  容差内低速稳定 0.5 秒，超出预计轨迹时间后再等 8 秒仍未到位则失败退出。
  保留反馈新鲜度、跟踪边界、指令看门狗和确认失能，不把按钮可用等同硬件就绪。
  网页速度按操作员要求由 5°/s 翻倍；遥操中的回零默认仍为 5°/s，不随此按钮调整。
- 网页策略持续执行至手动停止或保护触发，不设总时长，不自动归位。需要归位时，
  先停止并等待退出清理完成，再由操作员点击 **双臂下垂**。
- **停止**：在准备、模型执行和返程阶段都有效。点击停止、页面断开、平台关闭、
  反馈/推理故障或越界会停止并清理，不会因此自动开始归位。不做故障后自动重试。

## 配置

双臂下垂使用既有硬件零位，不需要以下模型专用配置。以下 `return_home` 是保留的
高级 CLI 返程接口，仅用于有明确非零目标与反向准备路径的调用，不是网页按钮的前提。

沿用已有 `preparation` 或 `preparation_profile`，在同一 policy profile 中添加：

```json
{
  "return_home": {
    "kind": "reverse_preparation_v1",
    "home_joints_rad": [0, 0, 0, 0.03, 0, 0, 0]
  }
}
```

上面的七个角度只是名义下垂姿态的**示例**，不是任何实物已测量/验收的坐标。
须根据该高级返程任务的安装、肘部余量、线束和现场空间确定目标。它不替代已经
写入电机的硬件零位，也不影响网页双臂下垂按钮的可用性。
名义几何的研究试运行沿用模型页已有的显式选择和标签，不冒充实测标定。

返程顺序是：从当前最后下发的关节参考衔接到准备路径的末端姿态，依次访问反向
准备路点，最后到配置的下垂姿态。相邻相同的机械臂路点合并；**不反放模型动作，
不反放准备时的开合夹爪命令**，返程保持进入时的夹爪目标，不自动丢下所持物体。
手动归位从新鲜实测姿态开始；自动返程保留最后下发参考，避免因为跟踪误差突然
把指令跳到实测位置。每个路点仍需反馈稳定、限速/限加速度、限位、超时和跟踪检查。

以上模型专用返程是配置的关节路点路线，不是碰撞规划，也不保证从任意抓取末态都能无碰撞地回到
准备位。首次启用前应由操作员确认末态到准备位的衔接、反向路径及携物状态；
桌面、工装或物体改变时重新核对。不能把“反向”当成路线天然安全的证明。

可选返程参数：`velocity_rad_s`、`acceleration_rad_s2`、`settle_tolerance_rad`、
`settle_samples`、`settle_timeout_s`、`maximum_duration_s`。默认沿用准备参数，
返程不能比准备路径更快。它们不改变硬限位、看门狗或失能清理。

CLI 对应开关是 `policy --home-only`（只归位，不加载模型或相机）和
`policy --auto-return-home`（仅显式定时回合正常到时后归位），两者互斥。
网页使用 `policy --until-stopped`，它禁止搭配 `--auto-return-home`。
保留 CLI 定时诊断接口，不给网页添加定时限制。沿用已有 `--robot`、
`--sides`、`--profile`，实物仍要求 `--config` 和 `--record`。仅提供开关不会
立即执行；真实运动由操作员启动。

网页双臂下垂使用独立的 `policy --robot classic --sides left right --calibrated-zero`
调用，并传入原有硬件 `--config` 与外部 `--record` 目录。该模式禁止模型 profile，
不构造推理器、相机或 Cartesian IK，也不依赖主臂连接。模型会话、遥操等运动
所有权仍互斥，停止/断连不会启动另一次归位。直达零位不是避障规划，操作员需
确认双臂、桌面、工装和所持物体的通路；不能假定任意姿态直线回零都无碰撞。

记录中新增 `return_home_started`、`return_home_waypoint`、`return_home_completed`，
返程阶段为 `return_home`，不计入策略运行时长。默认只保留紧凑摘要和生命周期，
不为归位自动生成图像、录像或完整轨迹。一次调用成功不代表实物归位已验收。
