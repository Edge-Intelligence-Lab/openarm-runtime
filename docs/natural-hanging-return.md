# 模型页归位到自然下垂

“归位”指执行 profile 中明确配置的自然下垂关节姿态，不是本轮开始前的任意姿态，
也不是放任机械臂断电落下。它会主动驱动机械臂，完成反馈到位检查后再正常失能。

模型页提供：

- **归位**：选择已注册执行配置后即可使用，不必加载模型。
  不读取相机，不启动推理服务；仍需有效的机器人/几何配置。
- 网页策略持续执行至手动停止或保护触发，不设总时长，不自动归位。需要归位时，
  先停止并等待退出清理完成，再由操作员点击 **归位**。
- **停止**：在准备、模型执行和返程阶段都有效。点击停止、页面断开、平台关闭、
  反馈/推理故障或越界会停止并清理，不会因此自动开始归位。不做故障后自动重试。

## 配置

沿用已有 `preparation` 或 `preparation_profile`，在同一 policy profile 中添加：

```json
{
  "return_home": {
    "kind": "reverse_preparation_v1",
    "home_joints_rad": [0, 0, 0, 0.03, 0, 0, 0]
  }
}
```

上面的七个角度只是名义下垂姿态的**示例**，不是任何实物已测量/验收的坐标。
须根据安装的关节零位、肘部余量、线束和现场空间确定自己的目标。软件没有内置一个
自动套用到所有安装的下垂角度；未配置时按钮不可用，配置错误在使能前拒绝。
名义几何的研究试运行沿用模型页已有的显式选择和标签，不冒充实测标定。

返程顺序是：从当前最后下发的关节参考衔接到准备路径的末端姿态，依次访问反向
准备路点，最后到配置的下垂姿态。相邻相同的机械臂路点合并；**不反放模型动作，
不反放准备时的开合夹爪命令**，返程保持进入时的夹爪目标，不自动丢下所持物体。
手动归位从新鲜实测姿态开始；自动返程保留最后下发参考，避免因为跟踪误差突然
把指令跳到实测位置。每个路点仍需反馈稳定、限速/限加速度、限位、超时和跟踪检查。

这是配置的关节路点路线，不是碰撞规划，也不保证从任意抓取末态都能无碰撞地回到
准备位。首次启用前应由操作员确认末态到准备位的衔接、反向路径及携物状态；
桌面、工装或物体改变时重新核对。不能把“反向”当成路线天然安全的证明。

可选返程参数：`velocity_rad_s`、`acceleration_rad_s2`、`settle_tolerance_rad`、
`settle_samples`、`settle_timeout_s`、`maximum_duration_s`。默认沿用准备参数，
返程不能比准备路径更快。它们不改变硬限位、看门狗或失能清理。

CLI 对应开关是 `policy --home-only`（只归位，不加载模型或相机）和
`policy --auto-return-home`（仅显式定时回合正常到时后归位），两者互斥。
网页使用 `policy --until-stopped`，它禁止搭配 `--auto-return-home`。
保留 CLI 定时诊断接口，不给网页添加定时限制。沿用已有 `--robot`、
`--sides`、`--profile`，实物仍要求 `--config` 和 `--record`。仅提供开关不会
立即执行；真实运动由操作员启动。

记录中新增 `return_home_started`、`return_home_waypoint`、`return_home_completed`，
返程阶段为 `return_home`，不计入策略运行时长。默认只保留紧凑摘要和生命周期，
不为归位自动生成图像、录像或完整轨迹。一次调用成功不代表实物归位已验收。
